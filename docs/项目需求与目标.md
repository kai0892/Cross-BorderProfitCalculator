# 功能与适用范围

## 跨境单品利润试算器

按售价、汇率与单件成本，计算利润、保本售价和目标售价。

## 输入

- 外币售价
- 人民币 / 1单位外币
- 采购成本（元）
- 物流成本（元）
- 包装及其他成本（元）
- 平台佣金（售价%）
- 广告分摊（元/件）
- 退款预留（售价%）
- 目标利润率（%）


## 运行与保存

在桌面浏览器中打开index.html。处理过程在本机完成，使用JSON备份保存与恢复数据。

## 功能说明

佣金和退款预留按售价比例计；不自动获取汇率、税率或平台费率。退款预留为简化预算。

## 验证要求

检查核心计算、无效输入提示、文件导出、备份恢复和界面显示。
